# Experiment 5.3.3 Gateway Network Sensitivity

Run from the code root:

```powershell
C:\Users\Owner\anaconda3\python.exe experiments\5.3-3\run_5_3_3.py
```

The single resumable command verifies upstream hashes, generates one size-specific teacher and fresh BC/full constrained-SAC training bundle for each of five network sizes, executes a validation-path timing gate, selects a formal matched-path count without observing test outcomes, evaluates all 25 declared structural cells, and creates tables, 300-dpi PNG figures, reports, acceptance JSON, and a hash manifest.

Passive, Reactive, and size-specific BC are evaluated in all cells. The projected stochastic MPC and model-guided constrained SAC are additionally evaluated only at the common three-gateway reference and the six nine-gateway architecture-by-eligibility endpoints. All other pairs are explicitly `NOT_EVALUATED_BY_DESIGN`.

New nodes are generic semi-synthetic median templates. The experiment is not a forecast for any named port.
