# Experiment 5.3.1: Commitment Sensitivity

Run from the `code 8.4` root with:

```powershell
C:\Users\Owner\anaconda3\python.exe experiments\5.3-1\run_5_3_1.py
```

The run is fail-closed against the accepted 5.2 input hashes. It creates new
teacher data and new BC/constrained-SAC checkpoints at every preregistered
commitment fraction. Evaluation caches are resumable only under the same
configuration, upstream-lock bundle, and production-source bundle.

The commitment fraction is a designed structural variable. It is not an
estimate of historical Hormuz cargo commitment. It changes only the split of
each newly blocked cohort and never relabels existing waiting or tagged mass.
